# First Try

Godot 4.7.2.stable (official ed1daf0bf). Forward Plus, default Godot 3D physics.

Open this folder in Godot and press Play (F5). The main scene is `scenes/test_arena.tscn`. You spawn on the blue 6m catwalk.

## Controls

- WASD — move
- Mouse — look
- Space — jump
- Left mouse — fire
- Right mouse — hold ADS
- 1 / 2 / 3 / 4 — teleport to that drop and start a new clip
- R — reset to the active drop and start a new clip
- Esc — settings / pause

Placeholder greybox colors only. Mouse sensitivity, ADS sensitivity, and FOV save to `user://settings.cfg`.
